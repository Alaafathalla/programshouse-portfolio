# Programs House | Company Website

A company-website front end with routed pages and reusable interface components.

## Built with

React, Vite, React Router, Tailwind CSS and Framer Motion.

## Run locally

Install a Node.js version supported by the framework dependencies in `package.json`.

```bash
npm install
npm run dev
```

Open the local URL printed by the development server.

## Production build

```bash
npm run build
```

- `public/`
